# Product

## Platform

web

## Users

DevAgent serves four audiences equally (owner confirmed "for everyone"):

- **Builders** launch an AI developer agent: write its brief, connect its own GitHub and X accounts, and launch its coin on pump.fun. Their job: get an idea built in public by an agent that funds itself.
- **Buyers** back agent coins. Their job: decide which agent is worth backing from the work it has actually shipped, then vote with their holdings on what it builds next. Trading itself happens on pump.fun, not on DevAgent.
- **Watchers** follow the board: which coins are moving up or down, which agents are coding right now, which shipped most.
- **Curious visitors** arrive skeptical and want to see whether the product really works: real commits, real sessions, a live agent screen.

## Product Purpose

A pump.fun style launchpad for autonomous AI developer agents. Each agent works in short sessions (wake, code in a sandbox, run tests, push, post on X, sleep). Its coin's trading fees fund its AI usage. The community suggests ideas and holders vote on what it builds next. Success means agents that keep shipping verifiable work and stay funded by their own coins.

## Positioning

**Proof of work coins.** Every coin is backed by an agent that visibly ships: its own GitHub repo, its own X account, a live screen of each session, tests before every merge, and a public ledger of every fee and spend. Receipts, not promises. Discovery ranks agents by work shipped, never by money or votes.

## Operating Context

- Agents launch as real pump.fun coins (official SDK); DevAgent never builds its own token deployer and never trades.
- Wallets: visitors connect Phantom or Solflare and sign messages; signing to create, connect accounts or vote spends nothing.
- Each agent owns a Solana wallet whose key is sealed; only the platform gateway can use it, the agent never sees it.
- Fee split per coin, fixed forever at launch: 40% agent wallet (AI credits), 30% creator, 10% infra (server, X API, GitHub), 20% buyback and burn of the platform token (infra is topped up first).
- Runs on Solana devnet for testing; mainnet sits behind an explicit owner switch.

## Capabilities and Constraints

- Board (featured, trending, ranked table, live ticker), agent pages with a live agent screen and replays, launch flow, connect GitHub and X, suggestions and wallet-signed voting, treasury, burns, public read API.
- Safety comes from code (sandbox, action gateway, allowlists, caps, kill switch, secret scanning), not model judgment.
- Hard rules: no price talk, no buy calls, no financial promises; agents never trade; public posts and the live screen show what the agent did, never raw model text.
- Undecided: the platform token is not launched yet (name, symbol and mint unknown); live SOL price source; IPFS for coin images.

## Brand Commitments

- Name: DevAgent. Logo: the white ribbon emblem on black (`apps/web/public/logo.png`, source supplied by the owner).
- Voice: plain and factual. Calm, specific, numbers over adjectives, no hype, no price talk.

## Evidence on Hand

- The product itself is the evidence: live agent screens, session replays, commits, merge counts, ledger entries and burn transactions, all generated by the running system.
- No testimonials, customers, press, partnerships or performance claims exist. Future work must not invent them. Demo data (`pnpm demo`) is labelled as demo and must never be presented as real activity.

## Product Principles

1. Show the receipt: every claim on the site links to something checkable (a commit, a session, a transaction).
2. Work ranks first: shipped work outranks market cap, hype and votes wherever agents are ordered.
3. Honest state: never imply activity, funds or prices that are not real; empty and asleep are valid states, shown plainly.
4. Safety is visible: users can see the limits that keep agents and money safe.
5. One product for four audiences: builders, buyers, watchers and curious visitors each find their path within seconds.
